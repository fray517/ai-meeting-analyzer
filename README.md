# AI-анализатор видеовстреч

Локальное приложение для записей Яндекс Телемоста и Zoom. Оно принимает MP4 и WebM размером до 250 МБ с компьютера или по публичной ссылке Яндекс Диска и рассчитано на встречи длиной 2–5 минут. Можно обработать одну запись за раз.

## Запуск

1. Установите Node.js 22 или новее и FFmpeg. Команды `node --version` и `ffmpeg -version` должны работать в терминале. Путь к FFmpeg также можно задать в `FFMPEG_PATH`.
2. Распакуйте архив и откройте терминал в папке проекта. Скопируйте `.env.example` в `.env`. В PowerShell выполните `Copy-Item .env.example .env`.
3. Запишите свой ключ OpenAI API в строку `OPENAI_API_KEY=` в файле `.env`. Нужен доступ к API и моделям. Ключ остаётся на стороне сервера. Не включайте `.env` в материалы сдачи.
4. Выполните `npm start`. Устанавливать npm-зависимости не требуется.
5. Откройте [http://127.0.0.1:3000](http://127.0.0.1:3000). Выберите или перетащите видео. По окончании обработки раскройте встречу в истории, затем нажмите «Расшифровка». При ошибке прочитайте сообщение и выберите файл повторно.

Для другого порта задайте `PORT` в `.env` и используйте адрес, который сервер выводит при запуске.

## Импорт с Яндекс Диска

1. Загрузите учебный MP4 или WebM в Яндекс Диск и скопируйте публичную ссылку на отдельный файл. Проверьте, что скачивание по ссылке разрешено.
2. В разделе «Анализ встреч» вставьте ссылку в поле «Ссылка на видеозапись» и нажмите «Добавить из облака».
3. Откройте карточку в истории. Приложение показывает этапы «Получение файла», «Распознавание речи», «AI-анализ» и «Готово». При сбое появляется состояние «Ошибка» с пояснением.
4. Если Диск ограничил скачивание или запрашивает вход, скачайте файл в браузере, если у вас есть доступ, и выберите его через «Выбрать видео».

Для публичных файлов используется [REST API Яндекс Диска](https://yandex.ru/dev/disk/rest/). При повторном добавлении приложение сравнивает SHA-256 скачанного файла с готовыми облачными записями. Если содержимое совпадает, оно предлагает открыть сохранённый результат. Если файл изменился, запускается новый анализ. В истории сохраняется хеш нормализованной ссылки. Сама ссылка в историю не записывается.

## Обработка и хранение

- FFmpeg извлекает первую звуковую дорожку в моно WAV. Для распознавания используется [OpenAI GPT Transcribe](https://developers.openai.com/api/docs/guides/speech-to-text).
- Конспект составляет `gpt-4.1-mini` через [OpenAI Responses API со структурированным выводом](https://developers.openai.com/api/docs/guides/structured-outputs). Модели можно задать в `.env`.
- Для распознавания в OpenAI передаётся аудио, для конспекта — текст. Используйте собственную учебную запись или запись, на обработку которой участники дали согласие.
- История хранится в `data/` рядом с сервером и доступна после обновления страницы и перезапуска. Видео и извлечённое аудио используются временно.
- Функция `processVideo(videoPath)` из `process-video.mjs` принимает путь к локальному видео и возвращает расшифровку и конспект. Её можно вызвать и для файла, предварительно скачанного из облака.
